research_helpers.prose

This module tracks every number a document states in prose and links it to the data that supports it, as well as auditing the prose for untracked numbers. See numbers in the prose.

class research_helpers.prose.ProseNumber(key, template, values, source='', section='', document='paper')[source]

One fragment of a sentence as the document prints it, and how to compute its numbers.

‘template’ is the fragment with ‘{}’ where each number goes and doubled braces for literal ones, so ‘(Q_{{ov}} = {})’. Whitespace is immaterial: the fragment and the document are both compared with every run of whitespace collapsed to one space.

research_helpers.prose.audit(text, entries=(), *, tables_dir=None, parameter_symbols=())[source]

Classify every numeric token in a manuscript’s prose.

Each token falls in the first category that accounts for it:

  1. registered: it lies inside a fragment one of the entries describes.

  2. notation: it is a constant of an inline formula, or a parameter’s value in one that assigns a declared parameter symbol. Not a result.

  3. cited-float: it appears in a generated table the same paragraph cites, which carries it.

  4. other-float: it appears in a generated table the paragraph does not cite.

  5. untraced: none of the above. These are the numbers to pin.

Numbers in the preamble, comments, display math, citations, labels, references and the arguments of ‘input’ and ‘includegraphics’ are not prose and are skipped.

Parameters:

  • text (str) – the manuscript, as written.

  • entries (Sequence[ProseNumber], default: ()) – the registry entries for this manuscript.

  • tables_dir (Path | str | None, default: None) – where its generated tables are, named by label without the ‘tab:’ prefix.

  • parameter_symbols (Collection[str], default: ()) – see ‘ProseRegistry’.

Return type:

list[Occurrence]

Returns:

Every token, in document order.
