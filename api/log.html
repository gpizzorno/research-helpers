research_helpers.log

Provides structured logging over the standard library. Requires the log extra. See Logging.

research_helpers.log.set_log_file(name, filename)[source]

Route one logger’s records to their own file.

Parameters:

  • name (str) – the logger name, as passed to ‘get_logger’ (normally a module’s ‘__name__’).

  • filename (str) – the file, relative to the configured log directory.

Return type:

Path

Returns:

The path records will be written to.

Raises:

RuntimeError – if file logging is not configured.

research_helpers.log.setup_logging(*, console_level=None, file_level=None, directory=None, colour=None, stream=None)[source]

Configure logging, replacing any configuration this module made earlier.

Parameters:

  • console_level (int | str | None, default: None) – minimum level shown on the console.

  • file_level (int | str | None, default: None) – minimum level written to file.

  • directory (Path | str | None, default: None) – where to write log files. None means console output only.

  • colour (str | None, default: None) – ‘auto’ to colour only a terminal, or ‘always’ / ‘never’.

  • stream (TextIO | None, default: None) – where console output goes, defaulting to stdout.

Return type:

None
